1. JSON 数据包格式 必须看懂

firmware/esp32_device/src/main.cpp :46-60

ESP32 通过串口发出的 JSON 字符串 格式如下，所有后续周（云上传、Agent 分析等）都基于这个数据结构。

// ESP32 构建 JSON 的核心代码
StaticJsonDocument<256> doc;
doc["device_id"] = "esp32_001";
doc["timestamp"] = now;

JsonObject sensors = doc.createNestedObject("sensors");
sensors["temperature"]["value"] = temperature;
sensors["temperature"]["unit"] = "c";
sensors["humidity"]["value"] = humidity;
sensors["humidity"]["unit"] = "%";
sensors["light"]["value"] = analogValue;
sensors["light"]["unit"] = "raw";

serializeJson(doc, Serial);  // 序列化为 JSON 字符串并发送

实际输出的数据长这样：

{
  "device_id": "esp32_001",
  "timestamp": 5000,
  "sensors": {
    "temperature": { "value": 25.3, "unit": "c" },
    "humidity":    { "value": 60.2, "unit": "%" },
    "light":       { "value": 2048, "unit": "raw" }
  }
}
理解要点：
  • device_id — 设备标识，将来多设备时区分数据来源
  • timestamp — ESP32 内部的毫秒计时（相对时间）
  • sensors — 嵌套对象，每个传感器有 value + unit
  • Python 端用 json.loads() 解析后可直接用 data["sensors"]["temperature"]["value"] 取值

2. 非阻塞定时 millis() 必须看懂

firmware/esp32_device/src/main.cpp :34-38

嵌入式编程最重要的模式之一。不能用 delay(5000) 阻塞，否则传感器读取期间 CPU 无法做其他事情。

const unsigned long SEND_INTERVAL = 5000;  // 5 秒间隔
unsigned long lastSendTime = 0;

void loop() {
  unsigned long now = millis();             // 当前开机毫秒数

  if (now - lastSendTime >= SEND_INTERVAL) {
    lastSendTime = now;                     // 更新"上次执行时间"
    // --- 这里执行传感器读取 + 发送 ---
    float t = dht.readTemperature();
    // ...
    serializeJson(doc, Serial);
    // LED 快速闪烁（用 delay(50) 只阻塞 50ms，可接受）
    digitalWrite(LED_BUILTIN, HIGH);
    delay(50);
    digitalWrite(LED_BUILTIN, LOW);
  }
  // 如果没到 5 秒，loop() 会立即返回，继续做其他事
}
类比理解： 想象你在煮泡面（5分钟），delay(5000) 是盯着计时器一动不动；millis() 模式是设个闹钟，闹钟响之前你可以刷手机（执行其他任务）。
关键区别： delay() 阻塞 CPU → 无法响应按钮、无法处理串口数据；millis() 非阻塞 → 每次 loop() 检查一次时间，没到就跳过。

3. 缓冲区模式 必须看懂

agent/src/week1_data_collection/data_receiver.py :26-55

数据采集系统标准做法：先攒一批数据在内存里，再一次性写入磁盘，避免每条数据都触发磁盘 I/O（太慢）。

class SensorDataReceiver:
    def __init__(self, data_dir):
        self.buffer = []          # 缓冲区：先存内存里

    def receive_data(self, raw_data):
        data = json.loads(raw_data)     # 解析 JSON
        data["timestamp"] = datetime.now().isoformat()  # 加接收时间戳
        self.buffer.append(data)        # 放入缓冲区
        return {"status": "ok", "data": data}

    def flush_to_disk(self):
        filename = f"sensor_data_{...}.json"
        with open(filename, "w") as f:
            json.dump(self.buffer, f, indent=2)  # 批量写入
        count = len(self.buffer)
        self.buffer.clear()           # 清空缓冲区
        return count
理解要点：
  • buffer 是一个 Python 列表，不断 append() 新数据
  • flush_to_disk() 一次性把列表里所有数据写入文件 → 比逐条写入快 10~100 倍
  • 文件名带时间戳（如 sensor_data_20260514_180000.json），每次刷新生成新文件
  • 写入完成后 buffer.clear() 清空，继续接收下一批

5. ADC 模拟读取 建议看懂

firmware/esp32_device/src/main.cpp :15,43
// 引脚定义
#define ANALOG_PIN 34      // 选用 ADC1（不受 WiFi 影响）

// 读取模拟值
int analogValue = analogRead(ANALOG_PIN);  // 返回 0 ~ 4095
为什么用 GPIO34？ ESP32 的 ADC 分为 ADC1（GPIO32~39）和 ADC2（GPIO0,2,4,12~15,25~27）。ADC2 会被 WiFi 占用，所以模拟传感器必须接 ADC1 的引脚。GPIO34 是 ADC1 通道 6。

数值范围： ESP32 是 12 位 ADC，返回值 0~4095。光敏电阻越暗，电压越低，数值越小。

6. DHT11 库用法 建议看懂

#include               // DHT 传感器库

#define DHTPIN  4             // 数据引脚
#define DHTTYPE DHT11         // 传感器型号：DHT11（也支持 DHT22）

DHT dht(DHTPIN, DHTTYPE);     // 创建 DHT 对象

setup() {
    dht.begin();              // 初始化传感器
}

loop() {
    float humidity    = dht.readHumidity();       // 湿度 %
    float temperature = dht.readTemperature();    // 温度 ℃
}
特性 DHT11 DHT22
温度范围 0~50 °C -40~80 °C
精度 ±2 °C ±0.5 °C
采样间隔 1 秒 2 秒

7. 串口初始化 建议看懂

firmware/esp32_device/src/main.cpp :25
Serial.begin(115200);  // 设置串口波特率

波特率 = 每秒传输的比特数。ESP32 和 PC 必须设为相同值，否则通信乱码。115200 是常用平衡值（速度够快且稳定）。

常见问题：如果串口输出乱码，先检查两边波特率是否一致！

8. 模拟器工作原理 建议看懂

agent/src/week1_data_collection/simulate_esp32.py :36-60

模拟器在没有真实 ESP32 硬件时生成模拟数据，输出格式与真实硬件完全一致。

def read_sensors(self):
    # 在上次值的基础上加随机波动
    self.temperature += random.uniform(-0.3, 0.3)
    self.humidity    += random.uniform(-1.0, 1.0)
    self.light       += random.randint(-100, 100)

    # 限制在合理范围内
    self.temperature = max(15, min(35, self.temperature))
    self.humidity    = max(30, min(80, self.humidity))
    self.light       = max(0, min(4095, self.light))

    return {"temperature": {"value": round(self.temperature,1), "unit": "c"},
            "humidity":    {"value": round(self.humidity,1),    "unit": "%"},
            "light":       {"value": self.light,              "unit": "raw"}}
为什么需要模拟器？ 第1周学习时你可能还没有 ESP32 开发板。模拟器在 PC 上生成一模一样的 JSON 格式，让你可以完整测试 Python 端的接收、存储、可视化代码。等拿到硬件后，只需把模拟器换成 serial_reader.py 即可。

if (!isnan(humidity) && !isnan(temperature)) {
